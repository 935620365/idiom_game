# 成语猜猜乐游戏插件

## 简介
成语猜猜乐是一个基于图片猜成语的趣味游戏插件，支持群聊和私聊场景。玩家通过观察图片提示，猜测对应的成语，每轮游戏包含5道题目，答对得分，答错可以继续尝试。

## 主要功能
1. 图片猜成语：通过观察图片提示猜测对应的成语
2. 智能提示：支持通过OpenAI获取智能提示和成语解释
3. 排行榜系统：记录玩家得分，支持查看历史排行榜和当前轮次排行
4. 时间限制：每道题目限时20秒，超时自动显示答案
5. 追问功能：支持通过"问+问题"获取更多提示
6. 游戏管理：支持随时结束游戏，查看帮助信息

## 游戏命令
- `开始游戏` 或 `猜成语`：开始新游戏
- `提示`：获取当前题目的智能提示
- `问+问题`：获取更多提示（例如：问意思、问出处）
- `我猜xxx`：提交答案（xxx为猜测的成语）
- `下一题`：跳过当前题目
- `结束游戏`：提前结束当前游戏
- `排行榜`：查看成绩排行
- `帮助`：查看帮助信息

## 管理员命令
- `重置排行榜`：清空所有排行榜数据
- `清理排行榜`：合并重复数据

## 游戏规则
1. 每轮游戏包含5道题目
2. 每道题目限时20秒
3. 答对一题得1分
4. 可以多次尝试，直到答对或超时
5. 超时后自动显示正确答案和解释
6. 游戏结束后显示得分和排行榜

## 配置说明
在`config.json`中可以配置以下参数：
```json
{
    "api_url": "成语API地址",
    "cache_timeout": 300,
    "questions_per_round": 5,
    "leaderboard_size": 10,
    "enable_openai": true,
    "openai_api_key": "你的OpenAI API密钥",
    "openai_model": "gpt-3.5-turbo",
    "openai_timeout": 10,
    "openai_api_base": "https://api.openai.com/v1",
    "game_settings": {
        "time_limit": 20,
        "auto_next_delay": 1,
        "correct_answer_delay": 3
    }
}
```

## 依赖要求
### Python版本要求
- Python 3.7 或更高版本

### 必需依赖包
```bash
# 基础依赖
requests>=2.25.1
python-dotenv>=0.19.0

# OpenAI相关
openai>=1.0.0

# 其他工具
pillow>=8.0.0  # 用于图片处理
```

### 安装依赖
可以通过以下命令安装所有依赖：
```bash
pip install -r requirements.txt
```

## 安装说明
1. 将插件文件夹`idiom_game`放入`plugins`目录
2. 复制`config.json.template`为`config.json`
3. 配置`config.json`中的参数
4. 重启机器人即可使用

## 注意事项
1. 需要配置OpenAI API密钥才能使用智能提示功能
2. 建议在群聊中使用，可以增加互动性
3. 游戏数据会保存在本地，重启后不会丢失
4. 管理员可以随时重置或清理排行榜
